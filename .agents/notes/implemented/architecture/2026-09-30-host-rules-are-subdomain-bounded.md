# Agent Note: 主机规则是子域边界匹配

Status: implemented

## Problem

`.ts.net` 这类写法有两种读法：「以这些字符结尾」与「这个子域边界之下」。两者对裸域名的答案不同，
而写下 `.ts.net` 的人想要的通常是后者。

## Decision

点开头表示**子域边界**：

- 命中 `dsh.example.ts.net`；
- **不**命中裸 `ts.net`（规则里那个点表示「前面还有点东西」）；
- 不命中 `evilts.net`（相同后缀，但不是子域）。

其余写法是精确匹配；要「什么都命中」就写 `*`。

## Alternatives considered

**按「以这些字符结尾」解释。** `evilts.net` 会被 `.ts.net` 命中：一条看起来收窄了的规则，实际把
无关主机放了进来。

**让 `.ts.net` 也命中裸 `ts.net`。** 那使用者就没有办法表达「只要子域、不要这个域本身」；裸域名
用精确匹配写出来并不麻烦。

## Consequences

- `*` 是唯一一个放弃收窄的写法，让使用者显式放弃，而不是靠一个含混的后缀。
- 这三条语义都有单测钉着（`test/page-hosts.test.ts`）：改判据要连着改它。
